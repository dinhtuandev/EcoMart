## 📋 Yêu cầu & Cài đặt
- **JDK**: Java 17 hoặc 21.
- **Maven**: Sử dụng `./mvnw` (Linux/macOS) hoặc `./mvnw.cmd` (Windows).
- **Database**: PostgreSQL 15+.

## 🚀 Chạy ứng dụng (Local)
1. Cấu hình file `.env` tại thư mục này dựa trên `.env.example`.
2. Chạy ứng dụng:
   ```bash
   ./mvnw spring-boot:run
   ```

## 📚 Tài liệu API & Swagger UI
- Swagger UI: `http://localhost:8081/swagger-ui.html`
